#### 🛎️ Featured: [Hotel Operations Knowledge Assistant](https://github.com/vamsialladev/hotel-ops-assistant)
Front-desk staff ask policy questions in plain English and get short answers with the source for every fact, for the right hotel. When the documents don't say, it refuses instead of guessing.

- **Messy real-world data:** property overrides, outdated versions, PDF tables, staff notes, scanned pages
- **Measured, not guessed:** 37-question eval with strict retrieval, citation and grounding checks, and a prompt-injection test
- **Production habits:** 31 unit tests, 92% coverage, CI, Docker, security notes, decision log
- **Business case:** projected value with pessimistic, base and optimistic scenarios, plus a pilot plan with go / no-go KPIs
